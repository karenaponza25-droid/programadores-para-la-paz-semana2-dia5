# Programadores para la Paz – Semana 2 Día 5

## Overview
Static HTML/CSS site featuring a community participation form ("Formulario Participa") for the Programadores para la Paz course. The project lives entirely under `semana2/` and contains:

- `semana2/index.html` – main form page
- `semana2/styles.css` – styles
- `semana2/checklist-accesibilidad.txt` – accessibility checklist
- `semana2/reflexion-verificacion.txt` – verification reflection

## Replit setup
- Workflow: `Start application` runs `python3 -m http.server 5000 --bind 0.0.0.0 --directory semana2` on port 5000 (webview).
- Deployment: `static`, with `publicDir = "semana2"`.

No backend or database is used.
